Name: Aclan, Trisha Mae M.

Activity: Week 14 – Flutter Foundations & Static UI Part 2
Screens Built: HomePageScreen (Screen 1) and MoreDealsScreen (Screen 2)

Overview
This project implements two static mobile screens StatelessWidget based on the selected wireframe design HOME PAGE and MORE, sharing a common ThemeData and built using Scaffold, SafeArea, Column, Row, Stack, Positioned, Container, Padding, SizedBox, and Expanded.

How to Preview Both Screens Without Navigation Logic
Navigation logic is intentionally omitted for this static UI activity:
1. Open lib/main.dart.
2. Preview Screen 1 (HomePageScreen): Keep home: const HomePageScreen() inside Week14App.build, then run/reload the app.
3. Preview Screen 2 (MoreDealsScreen): Change home: to home: const MoreDealsScreen(), then run/reload the app.
